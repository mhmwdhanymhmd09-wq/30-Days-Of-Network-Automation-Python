# Day 01: Subnet Calculator

A Python-based utility script designed to calculate and analyze IPv4 subnet details, network addresses, broadcast addresses, and host ranges using the built-in `ipaddress` library.

## Features
- Validates and parses user-inputted IP addresses and subnet masks.
- Computes network address, broadcast address, and total usable host capacity.
- Displays comprehensive subnet configuration details in a clean terminal layout.

## Requirements
- Python 3.x
- Built-in libraries: `ipaddress`

## How to Run
1. Open your terminal or command prompt.
2. Navigate to the `Day01-Subnet-Calculator` directory.
3. Run the script using the command:
   ```bash
   python subnet_calc.py
