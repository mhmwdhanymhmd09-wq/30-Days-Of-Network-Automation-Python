# Day 05: IP Geolocation Lookup Utility

## 🎯 Overview
A simple and efficient Python script designed to perform IP geolocation lookups using the `ip-api` service. It retrieves detailed geographic and network information for any target IP address, with a fallback option to check your own public IP.

## 🛠️ Features
* Queries geographic data including **Country, Region, City, and Coordinates (Lat/Lon)**.
* Fetches ISP and Organization details.
* Automatically detects your own public IP if the input is left blank.

## 🚀 How to Run
```bash
python3 ip_location.py
